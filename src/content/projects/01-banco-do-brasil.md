period: 06/2025 - Atual
bullets:
  - >-
    Lidero, como ponto focal, a evolução de uma stack interna baseada em Flask, integrando OAuth corporativo e sistemas legados pelo padrão Adapter e seguindo o design system do banco.
  - >-
    Reestruturei a camada SQLAlchemy com gestão automática de conexões e sessões, upsert e conversão de consultas em DataFrames; o suporte a PostgreSQL, IBM DB2 e SQLite simplifica o desenvolvimento de ETLs analíticos.
  - >-
    Criei um template Flask e uma CLI Tool para padronizar novos projetos, reduzindo drasticamente o tempo de preparação de interfaces novas.
  - >-
    Desenvolvi uma plataforma de avaliação de indicadores com API FastAPI, schemas Pydantic e agentes conectados ao hub de LLMs do banco; o fluxo iterativo propõe notas e melhorias até a validação dos indicadores.
